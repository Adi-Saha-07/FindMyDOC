⚙️ How to connect live Google Cloud credentials
To enable the automatic Google popup/consent screen with your own Google Cloud app:
  1. Visit Google Cloud Console → Create OAuth 2.0 Client ID (Web application).
  2. Under Authorized redirect URIs, add:
    https://findmydoc-lyart.vercel.app/google/callback
  3. Add GOOGLE_CLIENT_ID and GOOGLE_CLIENT_SECRET in your Vercel Project Environment Variables.
